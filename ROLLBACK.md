# Как откатиться

Всё, что сделано в версии 0.2.0, обратимо. Ниже способы от самого простого
к точечным.

## Точки отката

| Метка | Что это |
| --- | --- |
| тег `v0.1.0` | состояние опубликованного релиза 0.1.0 |
| ветка `backup-v0.1.0` | та же точка, но веткой — не потеряется при чистке тегов |
| коммит `03cfbd9` | `Publish consistently named release assets`, последний коммит 0.1.0 |

Ветка `backup-v0.1.0` создана специально под этот откат и никуда не двигается.

## Вернуть всё целиком

Отменить изменения новым коммитом, сохранив историю. Так безопаснее всего:
ничего не теряется, и откат тоже можно откатить.

```bash
git revert --no-commit v0.1.0..HEAD && git commit -m "Откат к 0.1.0"
```

Жёстко перевести ветку на старое состояние — история 0.2.0 останется только
в `backup-v0.1.0`:

```bash
git reset --hard backup-v0.1.0
```

Просто посмотреть старую версию, ничего не меняя:

```bash
git checkout v0.1.0
```

## Вернуть отдельный кусок

Каждый блок лежит в своём коммите, поэтому можно откатить только одну часть.
Список коммитов версии:

```bash
git log --oneline v0.1.0..HEAD
```

Отменить один коммит:

```bash
git revert <хеш>
```

Вернуть один файл в состояние 0.1.0:

```bash
git checkout v0.1.0 -- src/app.js
```

## Про атласы отдельно

Атласы пересобраны, а не отредактированы: исходные файлы 16×11 лежат в истории
git и в `assets/pets/runs/` (эта папка не в репозитории, но есть на рабочей
машине).

Вернуть старые атласы:

```bash
git checkout v0.1.0 -- assets/pets
```

Важно: сетка атласа задана в трёх местах, и они должны совпадать. Если
возвращаете старые атласы, верните и эти три файла:

- `ATLAS_COLUMNS` и `ATLAS_ROWS` в `src/petRenderer.js` (было 16 и 11);
- `background-size` в `src/styles.css` (было `1600% 1100%`);
- номера рядов в `PET_ANIMATIONS` в `src/petRenderer.js`.

Иначе питомец будет показывать не те кадры.

Собрать атлас заново из исходника:

```bash
python3 scripts/pack_atlas.py assets/pets/*/spritesheet.webp
```

## Настройки пользователя

Формат файла настроек не менялся, новые поля добавляются со значениями по
умолчанию. Версия 0.1.0 прочитает файл, созданный версией 0.2.0, и просто
проигнорирует незнакомые поля. Файл лежит здесь:

- macOS: `~/Library/Application Support/Напоминалка/napominalka.json`
- Windows: `%APPDATA%\Напоминалка\napominalka.json`

Если нужна страховка, скопируйте его перед обновлением.

## Откатить релиз на GitHub

Удалить релиз и тег 0.2.0, вернув `latest` на 0.1.0:

```bash
gh release delete v0.2.0 --yes --cleanup-tag --repo Isalin84/Napominalka
```
