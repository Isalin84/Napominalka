# Напоминалка

Небольшое desktop-приложение для тех, кто забывает сделать пару глотков воды, размяться или отойти от экрана. Вместо сухого уведомления в углу экрана появляется выбранный питомец. Он остаётся рядом, пока вы не подтвердите, что пауза действительно сделана.

Винни гавкает, Макс мурлычет, Совушка ухает, а Белочка щёлкает орешком. Звук можно выключить или сделать тише.

## Установка на macOS

При первом запуске macOS скажет, что не может проверить разработчика, и не пустит приложение. Так система ведёт себя со всеми программами, которые не куплены у Apple. Приложение рабочее, просто нужно один раз сказать системе «я доверяю». Это займёт минуту.

**Шаг 1.** Скачайте файл `Napominalka-0.2.1-arm64.dmg`, если у вас Mac на Apple Silicon (M1, M2, M3, M4), или `Napominalka-0.2.1-x64.dmg`, если Mac на Intel.

Не знаете какой у вас? Меню Apple в левом верхнем углу → «Об этом Mac». Если в строке «Чип» написано Apple — берите `arm64`. Если Intel — берите `x64`.

**Шаг 2.** Откройте скачанный файл двойным щелчком. Появится окно, где нужно перетащить значок приложения в папку «Программы».

**Шаг 3.** Откройте «Программы» и запустите «Напоминалку» двойным щелчком.

Появится окно: **«Не удаётся открыть приложение, так как его не удалось проверить на наличие вредоносного ПО»**. Нажмите **«Готово»**. Это нормально, продолжаем.

**Шаг 4.** Откройте меню Apple → «Системные настройки» → «Конфиденциальность и безопасность».

**Шаг 5.** Пролистайте окно вниз до раздела «Безопасность». Там будет строчка: «Приложение "Напоминалка" заблокировано, так как оно не от проверенного разработчика». Рядом кнопка **«Открыть всё равно»** — нажмите её.

Система попросит пароль от Mac или Touch ID. Это обычная проверка, что за компьютером вы.

**Шаг 6.** Запустите «Напоминалку» ещё раз. Появится последнее окно с вопросом — нажмите **«Открыть всё равно»**.

Готово. Дальше приложение открывается как любое другое, повторять ничего не нужно.

### Если что-то пошло не так

**Написано «Приложение повреждено».** Значит скачана версия 0.2.0, в ней была сломана подпись. Скачайте 0.2.1 или новее.

**Не нашли кнопку в настройках.** Она появляется только после того, как вы попробовали запустить приложение и получили отказ. Сделайте шаг 3, потом сразу шаг 4.

**Хочется быстрее и вы не боитесь терминала.** Одна команда вместо шагов 3–6:

```bash
xattr -dr com.apple.quarantine /Applications/Напоминалка.app
```

**На старых macOS (14 Sonoma и раньше)** проще: щёлкните по приложению правой кнопкой → «Открыть» → «Открыть» в появившемся окне.

### Почему так

Apple берёт 99 долларов в год за сертификат, который убирает это предупреждение. Пока такого сертификата нет, поэтому система и осторожничает. Приложение подписано, но не заверено у Apple.

## Установка на Windows

Скачайте `Napominalka-0.2.1-x64-setup.exe` и запустите. Windows может показать синее окно «Windows защитила ваш компьютер» — нажмите «Подробнее», затем «Выполнить в любом случае».

Если не хотите ничего устанавливать, скачайте `Napominalka-0.2.1-x64-portable.exe` — он запускается сразу, без установки.

## Что умеет

- выбрать одного из четырёх питомцев: Винни, Макса, Совушку или Белочку;
- напоминать о воде, разминке и своих делах по интервалу, времени и дням недели;
- откладывать напоминание, если сейчас неудобно;
- не показывать уведомления в тихие часы;
- жить в трее и запускаться при входе в систему;
- запоминать громкость и положение всплывающего окна на экране;
- проигрывать реальные звуки питомцев;
- показывать плавные покадровые анимации на прозрачном фоне;
- хранить историю отмеченных пауз локально, без аккаунта и облака.

## Как это устроено

Приложение написано на Electron. У каждого питомца есть прозрачный WebP-атлас: пять анимаций, до 12 фаз движения в каждой. Всплывающее окно всегда поверх остальных, но его можно перетащить туда, где оно не мешает. Закрытие главного окна прячет приложение в трей, напоминания продолжают работать.

Настройки хранятся на компьютере пользователя. Никуда не отправляются ни история пауз, ни расписание, ни выбранный питомец.

## Запуск из исходников

Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

Проверка текстов, склонений и сетки атласа:

```bash
npm test
```

## Сборка установщиков

```bash
npm run dist:mac
npm run dist:mac:x64
npm run dist:win
npm run dist:win:portable
```

Собранные файлы появятся в папке `dist`.
